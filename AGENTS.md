# Agent instructions: Baby Turtle Simulator

Before making significant changes, read PROJECT_BRIEF.md.

## Non-negotiable constraints

- This is a browser-based 3D game, not a desktop game.
- Use Babylon.js, TypeScript and Vite.
- Keep the additional project budget at $0.
- Never purchase assets, subscribe to services, activate paid API usage, or upgrade hosting.
- Do not use fal or any paid image, video, texture, audio or 3D asset-generation API.
- Use free software, self-created assets and properly licensed resources.
- Explain any external service or dependency before introducing it.
- Keep secrets out of Git and never place credentials in client-side code.

## Development process

- Work on one milestone at a time.
- Inspect the existing source code before editing it.
- Preserve working functionality when adding features.
- Prefer simple solutions that can be verified over elaborate untested architecture.
- Run the available tests and production build after significant changes.
- Clearly distinguish automated tests from things that require manual testing.
- Never claim that a controller, multiplayer connection or published website was tested unless it actually was.
- Give me the exact commands and steps needed to run each milestone locally.
- Explain important changes in language suitable for someone learning game development.

## Scope

Prioritize the first complete playable race. Add advanced visuals, additional turtle abilities and multiplayer in stages. Do not create an expansive open world or unnecessary account system before the core race works.
